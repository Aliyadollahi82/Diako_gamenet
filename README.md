# 🎮 Diako GameNet

A modern and responsive website for **Diako GameNet**, designed with a gaming-focused interface and a dark, immersive visual style.

## 🌐 Live Demo

[View Website](https://diako-gamenet.vercel.app/)

## 🛠️ Technologies

* Next.js 16
* React
* Tailwind CSS
* JavaScript / TypeScript
* HTML5
* CSS3
* Responsive Design

## ✨ Features

* Modern gaming-focused design
* Dark-themed user interface
* Fully responsive layout
* Mobile, tablet, and desktop support
* Game showcase section
* Gaming gallery
* GameNet services section
* Responsive navigation
* Persian RTL layout
* Optimized user experience across different devices

## 🎮 Gaming Experience

The website is designed to provide an engaging gaming atmosphere through:

* Game showcase
* Gaming images and gallery
* Modern dark interface
* Responsive gaming sections
* Easy navigation

## 📱 Responsive Design

The website is optimized for:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet

## 🚀 Getting Started

First, install the project dependencies:

```bash
npm install
```

Then, start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## 📦 Deployment

The project is deployed on **Vercel**.
